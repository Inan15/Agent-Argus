## 3. Challenges & Growth Areas

### 3.1 🔴 A guard that could not fail shipped — inside the epic whose signature subject is guard vacuity

**Story 16.7's `--map MEMBER_ID=RELATIVE_PATH` containment refusal could not fire on the platform it
was written on, and no test in the repository referenced `--map` at all.**

The shipped code read `if Path(relative).is_absolute(): raise Refused(...)`. On Windows
`Path('/etc/passwd').is_absolute()` is **`False`** — there is no drive — while `root / '/etc/passwd'`
**does** discard the root. So the refusal the script's own error message promised
(*"pathlib discards the left operand when the right one is absolute — which silently escapes the root
entirely"*) **never happened on the only leg anyone runs locally.** The iteration-1 review found it by
reading, filed it Low (the pinned-blob-hash check a few lines later bounds exploitability), and the
iteration-2 review then **proved it real by execution**: monkeypatching the old behaviour back in
memory and driving `main(["--map", "minions=/etc/passwd", ...])` — the escape was silently accepted
and the run died two members later on an unrelated missing checkout, exit `2`, with no refusal in
stderr.

**Three things make this the most instructive finding in the epic.**

**(a) It shipped inside the epic that names this class as its subject.** Story 16.6 is *about* the
assertion vocabulary. Story 16.7 §2.3 is titled *"Guard vacuity — this project's signature defect, and
this story's specific version."* AC7 opens *"a guard that cannot fail proves nothing, and this project
has shipped 4 of 35 unreal ones."*

**(b) The AC set could not reach it, and the mechanism is precise and worth registering.** ⛔ **AC7's
obligation is scoped to *"every new GUARD"*, and what shipped defective was a new REFUSAL that had no
guard.** For an unguarded branch, *"every new guard is driven RED"* is satisfied **vacuously — there
was no guard to drive**. AC7.1 then made this concrete by naming **three specific mutations**, all
three of them mutations of the *predicate* (`silent_class.py`'s scoring: remove `"AssertionError"`;
route through the frozen table; drop the `disc ≥ 1` conjunct). Those three were executed, observed RED,
and restored byte-exact — the discipline was performed exactly as written. **The enumeration became the
checklist, and the general clause above it was discharged against the enumeration.**

**(c) The AC that should have caught it is a list of past instances, not a property.** AC8.4
(*"POSIX PORTABILITY IS A CRITERION, NOT A HOPE"*) enumerates: decode explicitly, no bare `text=True`,
`encoding="utf-8"`, `newline="\n"`, repo-relative POSIX locators, ⛔ no `os.sep` / `os.path.join` /
literal backslash on a locator-building path. **Every item is about ENCODING or SEPARATORS. Not one is
about path ANCHORING.** The list was written from the instances already observed (`DF-16-6-F`'s cp1252
decode, the backslash locators) — and `-129`'s structural scan for a backslash string constant passes
trivially against a `PureWindowsPath`-based implementation. The review's own words: *"the same 'local
Windows-only gates, ubuntu CI leg' class of bug AC8.4 was written to catch, now present in one of
AC8.4's own untested corners."*

**The fix is genuinely good and is why this is a growth area rather than a failure.**
`_discards_the_root` now asks about the **anchor** — `pure.root or pure.drive` — under **both**
`PurePosixPath` and `PureWindowsPath`, so the answer is identical on both legs; the docstring states
the rejected alternative and names `..` as a **deliberate, disclosed scope exclusion** (a *visible*
traversal, not a *silent* discard). `TC-ArgusAgent-PRECISION-001-134` asserts on the **refusal message
content, not the exit code** — and iteration 2 proved by execution that an exit-code-only assertion

## 4. Key Insights

1. ⛔ **A non-vacuity obligation scoped to "every new GUARD" cannot reach a new REFUSAL.** This is the
   epic's sharpest technical finding and it generalises past this repository. AC7 was written, applied
   and honoured — three mutations at the real seam, observed RED, restored byte-exact — and the defect
   lived in a branch that had **no guard**, where the obligation is satisfied by having nothing to
   satisfy. The reachable form of the rule is *"every new refusal, halt, containment check or
   error path is driven to fire"*, not *"every new guard is driven RED."*
2. ⛔ **A portability AC written as a list of past instances protects against the past.** AC8.4 is
   seven precise, correct rules, all about encoding and separators — the two shapes previously
   observed. The eighth shape, path anchoring, was not on the list, and the guard that scans for
   backslash literals passes trivially against the `PureWindowsPath` implementation. **The list is a
   changelog of defects, not a statement of the property.**
2. **A guard's population is where its vacuity lives.** Three of this epic's findings are the same
   sentence with different nouns: the ceiling guard's population is `git ls-files`, so an untracked
   1,241-line file is invisible (§3.4); the `--map` refusal's population is the test suite, and no test
   named `--map` (§3.1); the review-filing check's population is *claims made*, so a finding that names
   no id is unreachable (§3.5). **Ask what a check enumerates before asking what it asserts.**
4. **"Found by the author's own executed mutation" is now a real, repeatable outcome, and it is the
   cheapest place in the loop to find this class.** Three instances (§2.4), each fixed by strengthening.
   The review gate found four more (§3.2). **A gate found zero.** The ranking is stable across the epic
   and it should drive where effort goes.
5. **A shared working tree is a first-class process input and this project treats it as weather.**
   Three collisions in one story, handled well three times, at a cost of one discarded suite run, one
   re-measured fix round and a permanent doubt about which sha any figure was taken at. The cost is
   paid per-worker, silently, and it does not appear in any metric.
6. **The epic ends where its charter started, and the record says so everywhere.** *"Nothing ratified.
   Nothing fetched. No detector run over a bench member. `DF-13-5-A` OPEN and UNSPENT."* That sentence
   appears in the status comment of 16.2, 16.3, 16.4, 16.5, 16.6 and 16.7. **Six stories in a row
   correctly declined to take an act reserved to a human.** That is the discipline working — and it is
   also six stories' worth of evidence that the act is the bottleneck, not the machinery.
