### 3.3 🟠 A guard fires on a story's PLAN, and whether it fires depends on the sentence, not the act

Story 18.4's Task 0 recorded the third of its three moved §0 rows plainly:

> ⛔ **The full suite is NOT exit 0 at HEAD `bd110c6` in this worktree.** `TC-ArgusAgent-DOCS-001-78`

1. **`-78`'s population is `stories/*.md` by glob, not by git** — an *uncommitted* story file is in

   future work, and the window stays open until the dev's last commit.
2. **What fires it is the prose, not the act.** `story_closure_claims` is line-scoped and anchored on a

3. ⛔ **There is no safe phrasing to teach.** *"to be closed by this story"* still matches the verb;
   only the negated forms are exempt, and a plan is not a negation. The convention that would avoid it
   — *"keep the id and the verb on different lines"* — is precisely the kind of rule that a future
   author cannot be expected to know.

This is the fourth consecutive instance of `AI-E13-1` / `AI-E14-4` / `AI-E15-13`'s class (*put a suite
gate on the phase that writes records*), and it is also the concrete case `AI-E13-3` opened and never

## 4. Key Insights

### 4.1 A finding and its proposed repair are two different artifacts, and only one of them was measured

Six wrong sentences reached four story files and **zero** reached a commit — because every story
executed the entry before adopting it. The general form: **an audit's observation is evidence; an
audit's recommendation is a hypothesis.** They were written in one voice, so a reader has no way to
tell which is which, and a 🟢 severity computed from a hypothesis is a scheduling decision made on a
guess. This project already knows how to mark epistemic status — `[re-derived here]`, *"measured, not
argued"*, `-146`'s FENCE-vs-WITNESS distinction — and the register is the one surface that does not.

### 4.2 A guard written for story *N* is the cheapest possible protection for story *N+1*

`TC-ArgusAgent-SECRET-001-26` was written on 2026-08-24 to pin one security property. On 2026-08-25 it
was the **only** test in a 1,724-case suite that stood between the ledger's recommended repair and a
recall defect on `UPPER_SNAKE_CASE` secrets. Nobody planned that. It is the strongest argument this
project has produced for *why* a story lands its guard **before** its fix, and for sequencing the
security story first.

### 4.3 A story's own artifacts join the population its acceptance criteria sweep

Three separate manifestations in one epic: a new test module joins `git ls-files` and carries a
finding (18.1); a repaired regex's own source line becomes a `high_entropy_string` match (18.3); a new
`rule_id` property becomes an `orphan_code` row (18.4). **A tool that audits its own repository has no
fixed population** — the act of satisfying an AC changes the number the AC is measured against. The
correction is mechanical: sweep at the story's own committed HEAD, never at the contexting snapshot.

### 4.4 The phases that write records are the phases with no gate — and now there are two symptoms, not one

Four consecutive retrospectives have asked for a suite gate on record-writing phases. Epic 18 shows
the class from **both** ends in the same epic: the contexting phase writing a record that turns the
suite RED (§3.3), and the review phase writing a record that never reaches the object database at all
(§3.1). The second is the more dangerous, because nothing goes RED to announce it.

### 4.5 Where a project standard and generic practice disagreed, the standard won — and it was right each time

Recorded, per this document's conflict-resolution rule: (i) generic practice says *fix the failing
test* — `DF-8-5-B` says fix the code, and 18.3's `-26` RED was the false-green alarm, not a broken
test; (ii) generic practice says *tidy the register* — `AI-E12-3` says a disposition is a governance
act with a named owner, so three falsifications were recorded **inside** entries rather than filed as
new ones; (iii) generic practice says *keep the module small* — 18.2's AC1.2 required the module to
grow by 19 lines to state a measured fact, and the ceiling (not the direction) is the real standard.
