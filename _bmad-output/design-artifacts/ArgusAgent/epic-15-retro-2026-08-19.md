## 2. What Went Well

### 2.1 The ordering discipline is real, mechanical, and verifiable by a stranger — and this retrospective verified it

Story 15.1's entire product is a property: **the selection criteria were frozen before anybody looked
at a candidate.** It is asserted three ways, and all three were checked in this session rather than
read:

| Claim | How it was checked here | Result |
|---|---|---|
| The criteria commit precedes the bench | `git merge-base --is-ancestor 16d7100 HEAD` | **true** `[re-derived here]` |
| The criteria commit contains no Argus output over any candidate | `git show --stat 16d7100` | touches exactly **two** paths: `scripts/candidate_selection.py` and the story file. No manifest, no candidate row `[re-derived here]` |
| The bench landed in a *later* commit | `git show --name-only c028da5` | `tests/corpus/_manifest.py`, `tests/test_candidate_selection.py`, `tests/test_validation_corpus.py` — three commits after the criteria `[re-derived here]` |

**Why this matters more than it sounds.** The failure this story exists to prevent is not *"too few
repositories."* It is choosing repositories **after seeing what the tool says about them** — the same
fallacy the Story 13.1 amendment rejected by name when it refused *"an externalization gate clearable
by a corpus the team authored, planted, and wrote the answers for."* Public repositories are a very
good disguise for that fallacy. Story 15.1's answer is a line stated exactly:

> A criterion may reference the **defect's DEFINITION**. A criterion may never reference the
> **tool's VERDICT**.

and then made **mechanical rather than promised** at both ends: `-74` walks the harness's AST and
fails if it can reach `argus.detectors.*` (with a non-vacuity floor requiring the walk to *see*
`argus.index`, so the absence is meaningful rather than a parsing artifact), and `-79` fails if any
candidate's recorded rationale contains detector-output vocabulary. A ban held at one end is a ban
somebody walks around; this one is held at both.

**The strongest single piece of evidence that the criteria were not retuned:** twenty repositories
were fetched and **six failed**, all six on criterion 2, and the floor was not moved to save any of
them. `pre-commit` misses by 9, `docker-py` by 6, `elasticsearch-py` by 5. `-77` pins
`COOCCURRENCE_FILE_FLOOR = 10`, `TEST_FILE_FLOOR = 50` and `HISTORY_SPAN_DAYS_FLOOR = 730` so a silent
retune is a test failure rather than a diff nobody reads.

## 4. Key Insights

1. **A gate returning zero is a statement about the bench at least as much as about the tool.** This is
   the epic's transferable lesson and it generalises well beyond Argus. The corpus over which every
   precision figure to date was taken contained **one** file carrying the co-occurrence the defect class
   requires. A detector cannot be shown either right or wrong against a population that does not contain
   the thing. **`UNEVALUABLE` was the correct answer and it was never a detector result.**
2. **Ordering is provable; intention is not.** Freezing criteria as *executable code in its own commit*
   converts an unfalsifiable methodological claim into `git merge-base --is-ancestor`. That is a pattern
   worth reusing anywhere a selection must be shown to precede an observation.
3. **The floor's credibility comes from the repositories it rejected, not the ones it admitted.** Six
   rejections, all on criterion 2, three of which clear the test-file floor comfortably — which is
   `DN-15-1-2`'s point re-measured on new data: **suite size does not carry the defect class**, and a raw
   test-count floor would have admitted all three.
4. **A halt with named options and declined alternatives is a higher-quality artifact than a completed
   task.** The first dev pass produced no bench and is the better half of this story's record: it
   established, by measurement, that the block was real, and it left the operator a decision rather than
   a fait accompli. **Two of the three options were declined, which is only possible because they were
   offered.**
5. **A guard that would have made the operator's act impossible is a guard that appointed itself the
   gate.** `-27`'s INTRINSIC-versus-PENDING partition is the sharpest single piece of engineering
   judgement in this epic, and it came from taking a RED seriously instead of adjusting until green.
6. **Exhortation does not close a recurring prose-accuracy defect; a narrow mechanism might.** A story
   that names the defect class in its opening section still produced it in its own debug log. The answer
   is not a stronger warning.
7. **Relieving ceiling pressure in one module can concentrate it in another.** The split that gave a test
   module 409 lines of headroom left the production module with 4. Both facts are true; only one was
   filed. Measure the whole population after a split, not the module you split.
