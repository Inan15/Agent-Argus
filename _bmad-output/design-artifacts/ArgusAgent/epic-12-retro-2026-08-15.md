### 3.4 🟠 The `DF-10-4-D` bootstrap cost one commit per story, halted the loop once, and is still worth its price — but the cost is now measurable and the design is fixable

Measured live: **10 of the epic's 28 commits are dogfood regenerations.** Every story that touched `argus/**` — 12.1, 12.2, 12.3, 12.4, 12.5, 12.6, 12.7, 12.8 — turned the artifact-currency guards red, and each was cleared by the same three-step: commit the `argus/` delta → run `scripts/regenerate_dogfood_artifacts.py` → commit the artifacts separately. The reds per story: 12.5 **2**, 12.6 **2**, 12.7 **6**, 12.8 **3**. 12.9 owed nothing, because `argus/**` was byte-unchanged and the story proved it.

**The operator ruling that made this possible was granted on 2026-08-12, before story one** (12-1 §0.1, discharging `AI-E11-2` / SD-1 verbatim), and it pre-authorised the sequence **for the whole epic**. That was the right call and it worked: zero blanket prohibitions, zero design compromises forced by a sha256, and the first story of the epic — which Epic 11's retro said would halt by construction — did not halt.

**What it did not fix is the loop's shape.** Every dev pass in the epic ran under its own no-commit instruction and therefore ended with the guards red and the two-step handed to the caller — *"this dev pass does not commit, so steps (1)–(3) are left to the caller"* appears verbatim in 12.5 §5, 12.6 §5, 12.7 §6 and 12.8 §5. On 12.5 that stopped the loop and required a standing human authorisation to continue. **So the pre-authorisation was granted at the epic level and never reached the worker that needed it.** The friction was not the guard; it was that the remedy sat on the far side of a boundary the dev pass could not cross.

**Assessment, asked plainly: the design is worth its cost, and the cost is avoidable.** The guard is not decorative — 12.1 proved the artifacts were **already wrong at HEAD with every assertion green** (§3.2 #1), so the currency property is real and was, until 12.1, unenforced. The refusal-on-dirty-tree is also right: an artifact citing a sha that does not contain the code it describes is exactly the evidence defect this project exists to delete. **Three improvements, in preference order:**

1. **Give the dev pass the commit.** `AI-E11-5` already put the commit in the loop's per-story close; extending that to *"commit the `argus/` delta, regenerate, commit the artifacts"* costs one step and removes eight red-handoffs and one halt. This is the smallest change with the largest effect.
2. **Let the script take an explicit `--allow-dirty-with-sha <sha>` for the pre-authorised sequence**, so the refusal remains the default and the authorised path is expressible rather than requiring a human between two steps.
3. **Decouple the enumeration from the index** (`enumerate_minions_source_files` reads `git ls-files`), which permanently removes the class. Carried forward unchanged from Epic 10's SD-3: this is **verdict-adjacent** and needs an explicit mandate, not a quiet fix.

### 3.5 🔴 The `--passes <typo>` false green survived four epics and every review gate that saw the flag, and the reason is structural

- **`--passes` was blessed by Story 10.3**, whose guards are about the *invocation contract* — `-35` (parser ↔ docstring equality), `-37` (defaults and shapes), `-38` (every flag names a contract site), `-28` (every documented command line parses). **Every one of those observables is about which FLAGS are accepted. Not one is about which VALUES are.** A guard cannot see a defect its observable excludes by construction — `AI-E11-1` clause (i), asked about the guard estate rather than about a single guard.
- **There was no set to validate against.** 12.8's record states it plainly: `generator.py` rendered its four report types through **inline `if "…" in enabled_set` literals** and *"there is no constant naming them"* — which is precisely why nothing could validate a report token. `_ALL_PASSES` existed, but nothing compared an incoming token to it.
- **The repository shipped a live instance and nobody noticed.** `.github/workflows/argus-student-audit.yml:48` has requested `vacuous-tests` — not a rendered report type — since commit `506bb73` (Epic 8/9, re-measured live), through Epics 8, 9, 10, 11 and four Epic-12 stories, and it was corrected in 12.8. It sat inside `-28`'s own corpus the entire time, and `-28` passed it, because `--reports vacuous-tests` **parses**.
- **Two Epic-12 stories touched the flag and did not find it.** 12.2 extended `--passes` with the `deep` token; 12.4 delivered outcome explanations over the same run. Both were correct within their own ACs.

**The generalisable lesson, and it is sharper than "add a check":** this project's flag-contract guards verify that the *specification* of the surface matches the *implementation* of the surface. They cannot verify that an accepted value **does what accepting it implies**. The class is *"a guard over the shape of an input, standing in for a guard over the effect of the input"*, and it is the input-side twin of the observable problem. 12.8 registered the fix for three flags in §Enforcement; the **general** rule — *a flag whose value is a member of a closed, code-defined set must refuse an unrecognised member inside `parse_args`, against the one definition of that set* — is what the next flag needs. **AI-E12-7.**

## 4. Key Insights

**1. A plan is a set of dated measurements, and this project has an exemption for its own planning documents that it grants nowhere else.** Argus refuses an undated figure in a README, in a CHANGELOG, in a release note, in an architecture table and in a ledger entry. `epics.md` states coordinates, counts and capability claims with no dates and no guards, and eight of nine stories found them wrong. The create-story re-measurement is not a hygiene step — **it is the only thing standing between the plan and the tree**, and it currently depends on an author choosing to do it.

**2. The vacuity class has an input-side twin, and Epic 12 found it.** Epic 11's five instances were all *"the observable cannot move when the defect does."* Epic 12 added a shape that is not the same: *"the guard verifies the SHAPE of an input as a proxy for its EFFECT."* `--passes securty` parses, satisfies every flag-contract guard, and silently disables every safety pass. `--reports vacuous-tests` parses and renders nothing, in the repository's own committed CI workflow, for four epics. **A contract guard proves the surface is described correctly. It proves nothing about what the surface does with what it accepts.**

**3. A story record is a published claim, and this epic proved the project does not treat it as one.** Every consumer-facing surface here is guarded in both directions, derived not transcribed, struck not deleted. Story files, sprint-status comments and checked task boxes are guarded by nothing — and four claimed ledger closures, one checked box over unimplemented code and one FR delivered into a function with no callers all passed review. **The evidentiary standard stops at the repository boundary of `argus/` and `tests/`, and the governance record is where the next false claim will live** — it already does.

**4. Pre-authorisation must reach the worker, not the epic.** The operator's `DF-10-4-D` ruling was granted before story one, was correct, and was cited by every story that needed it — and the dogfood guards still went red and stopped on 12.5, because the dev pass that hit them was under an instruction that forbade the authorised remedy. **An authorisation held one level above the agent that needs it is, at the moment of use, indistinguishable from no authorisation.**

**5. Fences addressed to a named successor are the only deferral shape that reliably executes, and this epic is the cleanest evidence yet.** Every hand-off written as *"this is Story 12.N's, by name, and here is the function/marker/line"* was collected: 12.5→12.8, 12.6→12.7, 12.7→12.8, 12.8→12.9. Every deferral written as an unowned ledger entry with `target_story: NONE` is still open — `DF-10-2-A` for the fourth consecutive retrospective, `DF-3-4-A` since Story 3.4, `DF-10-5-C`, `DF-10-3-B`, `DF-10-3-C`. **The difference is not priority. It is whether a specific later thing cannot proceed without it.**

**6. Rules land as practice, not as paragraphs — and practice does not survive an author who skips the file.** `AI-E10-5` landed universally and was never registered. `AI-E11-1` was applied by seven of nine stories and was never registered. Both spread because each story's author read the previous story's file. **12.4's author did not, and 12.4 is the story that broke every rule the practice encodes.** That is the failure mode of transmission-by-convention, observed rather than theorised, and it is the argument for registration that four retrospectives of asking politely has not made.

**7. The most valuable thing 12.9 found was not a defect in the code — it was that the most scrupulous sentence the project can write defeats its own reader.** The honest `NOT ESTABLISHED` statement must name the superseded run **with** its sha, or it is the half-truth the architecture illustrates with that exact run id. That shape is a well-formed citation, and any surface carrying it would have had every *other* unevidenced claim excused by evidence that was never offered. **A guard's vocabulary must be adversarial against the honest case as well as the dishonest one**, and the correction was made in the only safe direction: stricter, so adding a denial marker to your own sentence costs you the excuse rather than buying one.

**8. Epic 12 built the thing a developer would want on the first run, and there is still no first run.** Nine stories: the deep pass wired, the cache wired, every outcome explained, the ingestion boundary disclosed, the languages grounded, an MCP surface, packaged commands, a tool that explains itself and a fully staged release with sha256s and a preflight. **The repository is private. The tag does not exist. `origin/master` has not moved since 2026-08-09.** Everything in the charter except its last clause is done, and the last clause is the one that makes any of it reachable.
