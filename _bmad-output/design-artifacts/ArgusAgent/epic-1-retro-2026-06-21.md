## 2. What Went Well (Successes)

1. **The determinism spine held across all 7 stories with zero erosion.** The single canonical serializer
   (`apaa/store/canonical.py`, AR4) was reused *verbatim* in every later story — story 1.4's AC7 round-trip,
   1.5's findings, 1.6's verdict, 1.7's pipeline all flowed through it with **no second `json.dumps`**. The
   committed single-serializer lint/gate (`test_canonical_single_serializer.py`) stayed green at every step.
   This is the highest-leverage architectural decision in the epic: it made byte-identical determinism a
   *structural property* rather than a per-story discipline.

2. **The Fraction-not-float discipline (AR4) never broke.** Ratios/scores were stored as exact `Fraction`
   (or `Decimal`) from 1.1's pre-serialization validator (which *raises* `CanonicalSerializationError` on a
   `float` leaf) through 1.5's assertion-density/mock-ratio, 1.6's `deep_ratio`, and 1.7's pipeline. The
   verdict was fuzzed over 24 ledger-build orders → 1 byte string + 1 content_hash (1.6 review). The
   NFR-P1 byte-diff landmine the architecture flagged never detonated.

3. **The advisory-by-contract / false-accusation moat was verified non-bypassable at three independent
   layers.** Born in 1.5 (heuristic-only ⇒ `vacuous_test_heuristic` + `advisory` + `depth_supported=None`;
   only real two-fact AST corroboration promotes to `vacuous_test_ast`/`AUDITED_SHALLOW`), it was carried
   through 1.6 (`is_verdict_blocking` keyed on `depth_supported is not None`, NOT on `advisory`) and 1.7
   (the full pipeline preserved the moat end-to-end + a well-asserting fixture is NOT a false 🔴). Three
   reviewers independently confirmed it cannot be tricked into a fabricated 🔴. This is APAA's core trust
   property and it was built defensively from the first detector.

4. **Pure/impure separation (AR8) was clean and grep-verifiable.** Every story kept I/O, clock, subprocess,
   and LLM out of the pure modules (`ledger`, `verdict`, `canonical`, detector scorers) and at the impure
   shell only (`store/writer`, `repo_loader`, `cli`, `pipeline`). The verdict gate (1.6) imports *only*
   ledger/finding models — provably token-free (NFR-D2).

5. **Reuse-by-import of Minions leaf modules worked as designed (AR7).** 1.3 reused
   `lifecycle/workspace_artifact_writer` containment patterns; the no-web-imports gate
   (`test_no_web_imports.py`) was *extended, never forked*, and stayed green as each story added modules —
   confirming `apaa.*` transitively imports no `fastapi/uvicorn/starlette`.

6. **Honest degradation (AR10/NFR-R1) was a baseline, not an afterthought.** 1.7's pipeline degrades any
   error to a typed finding / exit 1, never an uncaught raise; 1.4's invalid-UTF-8 path degrades via
   `errors="replace"` (no crash, no fabricated success).

## 3. Challenges & Growth Areas

1. **The only review FAIL (story 1.4) was a platform-encoding defect that the determinism spine could not
   catch — and that no existing gate would have caught earlier.** `git ls-files` with default
   `core.quotepath=true` double-quoted + octal-escaped non-ASCII paths (`"caf\303\251.py"` → `.suffix ==
   '.py"'` → silently dropped), compounded by `subprocess.run(text=True)` decoding git's UTF-8 path bytes as
   cp1252 (Windows mojibake). Root cause class: **a subprocess/encoding boundary at the impure shell**, an
   area the pure-core determinism discipline does not reach. Fix: `git ls-files -z` (split on `\0`, bypass
   quotepath) + explicit byte→UTF-8 decode in `_run_git`; regression TC-APAA-INTAKE-001-78 (`café.py` +
   `naïve_dir/résumé.py`) written RED-on-old then GREEN.
   - **What would have caught it earlier:** the slice had no non-ASCII fixture in its intake tests until the
     reviewer demanded one. The lesson is that **impure-shell subprocess parsers need adversarial
     non-ASCII / locale fixtures by default**, because the determinism golden-tests (which operate on
     in-memory payloads) are blind to the OS-boundary decode.

2. **DF-1-7-B (interim Python deep over-grading) is a correctness gap that MUST close before the Epic-7
   dogfood.** In Tier-A, `grade non-test .py audited_deep` is a *claim-presence* check (correctly-scoped
   FR6/Epic-1), but full FR7 AST-truth-grounding is deferred to Epic-6 Story 6.2. Until 6.2 lands, APAA
   over-states Python coverage. This is **accepted as in-scope-deferred per the epics cut-order** (not a
   defect), but it is the single carried item with a hard downstream deadline: presenting the Minions
   dogfood (Epic 7) with un-grounded `audited_deep` claims would violate the red-team guard in 7.2 AC
   (`grade: demo-heuristic-only` flag). Owned by Story 6.2; severity 🟡.

3. **Defer register is split across two homes.** DF-1-3-A/B live in the central
   `APAA/deferred-work.md`; DF-1-4-A and DF-1-7-A/B live only in their story files' `### Review Findings`.
   The CC-3 six-field schema is present in all five, but a single source of truth would make the
   defer-inflow trend (CLAUDE.md §9.3) and downstream triage easier. Minor process debt.

4. **No previous-retro accountability loop yet.** This is Epic 1, so the L1-E11 "prior retro action items →
   next epic backlog" operating model (CLAUDE.md §9.1) starts *here* — this retro is the first link in that
   chain. The discipline to package these action items as Epic-2 backlog with enforcement-as-deliverable is
   untested for APAA and must be exercised deliberately.

## 4. Key Insights

- **A structural enforcement (single serializer + committed lint) beats a per-story convention.** The
  determinism spine held because it was a *gate*, not a promise — the exact lesson Minions learned as
  L8-E10 / L5-E11, now confirmed in a greenfield sub-project from story 1.
- **The trust-critical property (the false-accusation moat) was built before the feature that needed it.**
  1.5 locked the advisory-by-contract eligibility surface so that 1.6 and 1.7 could only *consume* it, never
  re-derive a weaker version. Building the moat at the detector layer (not the verdict layer) is why it held.
- **The pure-core determinism discipline has a blind spot at the impure shell's OS boundaries** (subprocess
  output decoding, locale, path quoting). Determinism golden-tests do not exercise it; adversarial encoding
  fixtures must.
- **Cut-order discipline is working but creates a dated liability.** Deferring FR7 AST-grounding to 6.2 was
  the right Tier-A call, but it converts a coverage *honesty* property into a tracked debt with a hard Epic-7
  gate. The cut-order is only safe if the deferred item is enforced at its deadline.
